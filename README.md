RAM Temizleyici
================

RAMTemizleyiciTested.exe veya RAMTemizleyiciSureliTested.exe uygulamasını çalıştırın.
Yönetici izni, Windows bellek listelerini temizlemek için gereklidir.

Özellikler:
- Fiziksel, sanal ve sistem çalışma seti göstergeleri
- Daire grafikler
- Eşik üzerinde otomatik temizlik
- Dakika aralığıyla süreli temizlik
- Sistem tepsisine küçültme
- Ayarlar paneli ve başlangıçta çalıştırma seçeneği

Not: Başlangıçta çalıştırma seçeneği kullanıcının Windows Run kaydına yazılır.
